Challenge-1

포인터 변수의 크기는 코드를 실행하는 컴퓨터의 운영체제와 CPU 아키텍처(32비트/64비트)에 따라 달라진다

포인터 변수는 메모리의 주소값을 저장하는 것이 목정이기에 32bit system에서는 주소의 최대길이가 4byte이기에 포인터 변수 또한 4byte, 64bit systemp에서는 주소의 최대길이가 8byte이기에 포인터 변수 역시 8byte를 갖는다.

Challenge-2

배열의 이름은 컴파일 과정에서 배열의 첫 번째 원소를 가리키는 포인터(시작 주소값)로 변환하기에 arr[i] 방식과 *(ptr + i) 방식 모두 컴파일러는 동일하게 처리한다. 따라서 배열 이름(arr)과 포인터(ptr)가 동일하게 동작한다

Challenge-3

Call by Value는 함수가 실행되는 순간 매개변수용 새로운 공간을 만들어 원본 값을 복사하여 이를 함수 내부에서 사용한다.
Call by Reference는 함수가 실행되는 순간 새로운 공간을 만드는 것이 아닌 원본 주소를 전달하여 이를 공유하며 사용한다.

따라서 원본 데이터가 훼손되어서는 안 되는 경우 Call by Value를 사용하고, 원본 데이터를 직접 조작해야 하거나 복사 비용이 너무 큰 경우 Call by Reference를 사용해야한다.
