## 🕹️ Challenge 2. 워게임 문제 풀기
- **선택한 문제:** Dreamhack - basic_exploitation_001
- **취약점 분석:** `gets(buf)` 함수에서 입력받는 문자열의 길이를 검증하지 않아, 제한된 버퍼 크기를 넘겨 스택 영역을 조작할 수 있는 스택 버퍼 오버플로우(Stack Buffer Overflow) 취약점이 존재합니다.
- **익스플로잇 설계:** `buf` 변수에서 함수의 반환 주소(RET) 영역 직전까지의 거리인 132바이트(버퍼 128 + SFP 4)를 의미 없는 값('A')으로 가득 채웠습니다. 그 후, RET 자리에 프로그램 내부에 존재하는 `read_flag()` 함수의 시작 주소인 `0x0804868b`를 리틀 엔디언 형태(`\x8b\x86\x04\x08`)로 덮어씌워 플래그를 출력하도록 유도했습니다.
