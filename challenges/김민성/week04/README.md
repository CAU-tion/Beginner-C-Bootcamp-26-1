## Challenge1. 함수 작성 및 호출  구조 이해

### 함수를 쓰는 이유
- 코드 재사용: 같은 코드를 여러 번 작성하지 않고 함수로 만들어 반복적으로 사용 가능
- 가독성 향상: 기능별로 코드가 나뉘어서 이해하기 쉬움  
- 유지보수 용이: 수정 시 함수만 수정하면 되므로 유지보수에 용이함

---

### 함수를 사용하기 유용할 때
- 반복적인 작업이 있을 때
- 여러 사람과 함께 모여 협업을 할 때 역할을 함수 단위로 나눠서 개발 가능 
- 큰 문제를 작은 문제로 분할할 때

## Challenge2. gdb로 스택 프레임 관찰

### 스택 프레임이란 무엇인가?
함수가 호출될 때 생성되는 Stack 영역의 함수 실행 공간.
이 스택에는 함수를 동작하는데 필요한 모든 데이터가 저장됨.
함수 호출과 함께 생성되고 함수 호출이 끝나면 같이 소멸됩니다.
